# Hebrew style guide

Use natural, concise modern Hebrew without niqqud. Keep dialogue in logical
reading order. Preserve all markup tokens, timing values, button placeholders,
impact markers and explicit line breaks. Prefer shorter phrasing to crammed
speech bubbles. The builder validates tags and wraps long lines by glyph width.

Names: Otus אוטוס; Geddy גדי; Alphonse אלפונס; Asio אסיו; Solus סולוס;
Twig טוויג; Dirk דירק; Molstrom מולסטרום; Strix סטריקס; Buccanary בוקנרי;
Toby טובי; Mandolyn מנדולין; Bomboman בומבומן.
Places: Vellie וולי; Advent אדוונט; Tropos טרופוס; Mesos מזוס;
Owl Temple מקדש הינשופים; Floating Continent היבשת המרחפת.
Terms: owl ינשוף; owls ינשופים; pirates פיראטים; gunner צלף;
relic שריד; Ancient Owls הינשופים הקדמונים; Great War המלחמה הגדולה;
Hex הקס; coins מטבעות; Boguin בוגווין.

Otus, Geddy, Asio, Alphonse, Solus, Twig, Dirk and Molstrom are male.
Buccanary and Mandolyn are female. Asio is stern and formal. Geddy is friendly
and conversational. Alphonse is courteous and theatrical. Keep humor, stammers,
repeated syllables and deliberate pauses without turning dialogue into literal
English syntax. Preserve semantic emphasis even where Hebrew word order differs.

Translate interface labels compactly. Keep controller button names (A, X, LT,
RB etc.), file paths, URLs, resolution strings and technical identifiers intact.
Do not translate the language_id metadata as dialogue. Record uncertain entries
for review rather than silently dropping meaning. No external translation API.
