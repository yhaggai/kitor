# Jenny LeClue Hebrew localization glossary

## Authorship and scope

The complete logical-order source was freshly translated from English by **OpenAI gpt-6-astra** on 2026-11-07. Reasoning effort was **high**, verified from the parent’s explicit spawn metadata (`model=gpt-6-astra`, `reasoning_effort=high`, `fork_turns=none`). The translator read English-only, scene-ordered source dumps and authored all 5,511 catalog entries and all 89 menu entries. This was not a comparison against, or a selective cleanup of, the prior Argos draft. Exact duplicate random-dialogue strings in the same scene/context were reused only after source equality checks.

The catalog has 5,215 freshly authored/reviewed dialogue, choice, and nonverbal entries, plus 296 reviewed nonlinguistic production cues retained verbatim. Punctuation-only responses, Latin quotations, literal codes, and the HLC cipher initials are intentionally retained where the scene requires them. Each catalog row records the model and pass. `provenance.json` records the complete source pass and validation.

Earlier Argos translate-en_he 1.5 output and targeted Codex edits describe the **superseded draft**, not the current logical Hebrew. Pointed Hebrew must be derived from this source once; it is not a second independent translation.

## Verification and remaining limits

All 5,511 source English strings were checked against their original serialized offsets in the extracted `dialog14051`–`dialog14079` source files under `/tmp/jenny-hebrew.0rNS7c`. IDs are unique and unchanged. All rich-text tags and timing/voice controls retain their exact ordered tokens, including malformed source markup. All original line-break counts are preserved. All 24 embedded `RandomLine` fields retain their syntax and number of alternatives. All 296 production cues are verbatim source.

The 89 menu English values were extracted from `resources.assets` object 14120's English table. Menu key set, tag sequences, and line-break counts match that table. Seven catalog rows deliberately express source digits as Hebrew words; IDs are recorded in provenance.

This pass verifies translation source, not a complete playthrough. In particular, the radio/codebook letter-extraction puzzle uses English cover messages and Latin HLC initials in its source logic. Translated spoken text does not prove that the underlying letter-selection interface is localized or solvable in Hebrew. Verify the codebook and extraction assets in-game before claiming a fully Hebrew puzzle. Cross-family gravestone image labels and other image-only writing also require renderer/asset review. Speaker-less student exchanges and some background chatter use context-based agreement; no dedicated speaker-key inventory was supplied for those rows.

No font, packaged delta, or pointed catalog was changed by this translation pass. Regenerate pointed text and both platform artifacts from this exact source before release.
