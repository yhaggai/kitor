# Native Special Edition Hebrew

Install the Windows Special Edition from Steam or GOG, then scan its folder in Kitor. The native entry runs the remastered graphics directly. The classic ScummVM entry remains separate.

Install Hebrew and choose **French / Français** in the language selector (this slot contains Hebrew). Enable subtitles. Monkey Island 2 requires Steam to be running and a complete installation including steam_api.dll.

Experimental adaptation: classic dialogue credits remain with AdventureBrew; menus are newly translated. Unmatched dialogue stays English. Full-game coverage and paragraph wrapping remain under review. Uninstall in Kitor restores only affected files and preserves saves.

If menus remain English, check the game's language in Steam → Properties → General. This candidate stores Hebrew in the French slot; Steam still calls that slot French. This language setting was verified with the Hebrew game resources.

Version 0.2 adds Hebrew subtitles and bitmap fonts when switching graphics with F1. Opening scenes and switching back were tested in both games. Unmatched text can still remain English. Start a new game for verification; older saves may reference script positions from before this update.
