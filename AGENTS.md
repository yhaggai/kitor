# Tests

Keep new and edited tests in dedicated test files. When changing tests, follow the [separate-test-files skill](.agents/skills/separate-test-files/SKILL.md).

# GitHub Actions

When editing workflows or composite actions, follow the [Kitor GitHub Actions skill](.agents/skills/kitor-github-actions/SKILL.md). Pin external actions and reusable workflows to full commit SHAs and verify new or changed references before pushing.
