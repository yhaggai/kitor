# Monkey Island 2 native Hebrew package

This directory follows the standard `<game-id>/he/` package layout: `patch.json`,
`recipes/`, coverage, provenance, and validation results.

The two Monkey Island editions share their [build tools](../../monkey-se-native/he/prototype/)
and [build instructions](../../monkey-se-native/he/README.md). Pass MI2's input
directory to the shared builders; use `--game 2` where that option is provided.
See the shared [translation and tool credits](../../monkey-se-native/he/licenses/CREDITS.txt).

Select French in Steam to load Hebrew. The original executable is preserved.
F1 classic/remastered transitions and speech were checked in the opening scenes;
unmatched text and full-game compatibility remain documented limitations.
