# Where to Purchase

The Secret of Monkey Island: Special Edition is available from:

- [Steam](https://store.steampowered.com/app/32360/)
- [GOG.com](https://www.gog.com/game/the_secret_of_monkey_island_special_edition)

## Installation

1. Purchase and download the game from one of the stores above
2. Install to any directory on your computer
3. Return to Kitor and click "Add Game" or use "Scan Folder" to detect it

## Notes

After installation, the Hebrew patch can be applied from the Patches section.
The game requires ScummVM to run - Kitor will download it automatically if needed.
