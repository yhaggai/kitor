# אי הקופים 2: נקמתו של לצ'אק - מהדורה מיוחדת

הולך ברנשצבע מדחי אל דחי
את אגרויסע מציאה מחפש הוא בבכי
לה צ'אק האיום לו מלכודת טמן
ואפילו אילנה כבר לא בעניין
נצא מחדש למסע חתחתים
אחר האוצר חסר התקדים
בזאת את סדרת אי הקופים השלמנו
בתקווה שיהא זה שכרנו בעמלנו.

אז כן כן, אי הקופים מספר 2 יצא לאור! המשחק שאומנם דילגנו עליו מסיבות ש(אינן) שמורות איתנו, אבל למעשה לא שכחנו ממנו אפילו לרגע. במשך כשנתיים ישבו והשקיעו בו ממיטב מרצם רבים ונכבדים מחברי הקהילה ובסופו של דבר יצא משחק מרהיב מאין כמוהו. תרגום מדהים ומבריק, ביצועים גרפיים שלא מן העולם הזה, וירידה עד לפרטי הפרטים הקטנים ביותר. אנו שמחים שהגיעה השעה בה נוכל סוף סוף לחלוק איתכם את האושר הגדול הזה.

את המשחק שאתם מחזיקים בידכם מעטרים רקעים מרהיבים דוברי עברית פרי מכחולם של ניב באר ואורגד שנה, שדאגו גם לשיפורים וליטושים טכניים שונים במשחק ובמנוע לחוויה מושלמת.

וכמובן, כיאה למשחק עם כזו ציפיה, על התרגום שקדו רבים וטובים, ולהם נרצה להודות גם כן:
נתנאל אטלי, ניב באר, אלעד הלפרין, אלעד אברהם כהן, עומר כהן, אסף קפלן, שני רוז, אריאל רוזנטל, גיא-בראש שטח, אורגד ורייזל שנה, איילת שריד.

תודה מיוחדת לאורגד שנה שדחף, קידם, עיצב, הוביל, תיקן, גיהץ וליטש עד הפרט האחרון.


רוכשים את המשחק בגרסתו המחודשת מגוג או מסטים:

- [Steam](https://store.steampowered.com/app/32460/Monkey_Island_2_Special_Edition_LeChucks_Revenge/)
- [GOG.com](https://www.gog.com/en/game/monkey_island_2_special_edition_lechucks_revenge)

מורידים את הטלאי ומכווינים אותו אל תיקית המשחק


## התקנה במק דרך GOG

1. מתחברים בהגדרות קיטור לחשבון GOG שבבעלותו המשחק.
2. בכרטיס המשחק בוחרים **GOG Install game**, בוחרים תיקיית התקנה ולוחצים **Next**.
3. קיטור מוריד את מתקין Windows באנגלית, מחלץ את קובצי המשחק ומוסיף אותו לספרייה. לחיצה על **Play** מפעילה את הגרסה הקלאסית דרך ScummVM.

הטלאי העברי מותקן בנפרד, לפי בחירתכם. הגרפיקה המחודשת אינה נתמכת דרך ScummVM; לגרסה המחודשת יש כרטיס נפרד בקטלוג.
