Hebrew with nikud is a separate UNDERTALE translation option for Windows and
macOS. The original Hebrew without nikud option remains available and keeps its
own update track.

Select the desired option under Translation in Kitor. If another translation is
installed, restore it first, then install the selected option. Both packages
modify only the supported game archive and use Kitor's selective backup workflow.

This is an alpha with machine-generated vowelization. Linguistic review and
in-game playtesting remain outstanding. Keep English selected in the game.
