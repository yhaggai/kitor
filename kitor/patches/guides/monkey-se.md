# Where to Purchase

The Secret of Monkey Island: Special Edition is available from:

- [Steam](https://store.steampowered.com/app/32360/)
- [GOG.com](https://www.gog.com/game/the_secret_of_monkey_island_special_edition)

## Installation on Mac from GOG

1. Connect the GOG account that owns the Special Edition in Kitor Settings.
2. On the game’s card, choose **GOG Install game**, select an installation folder, and click **Next**.
3. Kitor downloads the English Windows installer, extracts its game data, and adds the game to your library. Click **Play** to run the classic adventure through ScummVM.

The Hebrew patch is optional and can be installed separately. ScummVM uses the classic game data inside the Special Edition; the native remastered edition has a separate catalog entry.

## Manual installation

1. Purchase and download the game from one of the stores above
2. Install to any directory on your computer
3. Return to Kitor and click "Add Game" or use "Scan Folder" to detect it

## Notes

After installation, the Hebrew patch can be applied from the Patches section.
The game requires ScummVM to run - Kitor will download it automatically if needed.
