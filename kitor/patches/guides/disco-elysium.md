# דיסקו אליסיום — The Final Cut

התקינו את [The Final Cut ב־Steam](https://store.steampowered.com/app/632470/) וסרקו את ספריית המשחקים בקיטור. אפשר גם לבחור ידנית את תיקיית המשחק ב־Windows או את חבילת `disco.app` ב־macOS.

לאחר ההתקנה בחרו **HEBREW** בהגדרות השפה של המשחק כדי להציג את התרגום לעברית. התרגום חלקי וחלק מהטקסט והתמונות עשויים עדיין להופיע בערבית.
